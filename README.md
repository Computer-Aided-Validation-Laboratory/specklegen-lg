# specklegen-lg
Speckle pattern generator python package

## Brief description of usage
### Speckle pattern generation
Generates random speckle patterns for DIC (Digital Image Correlation) and similar optical measurement applications. The algorithm subdivides the image domain and probabilistically places black and white speckles based on a target speckle size, creating high-quality patterns suitable for experimental validation.

### Speckle pattern saving
Generated patterns can be saved as `.tiff` or `.bmp` files. The `.tiff` format is recommended for lossless storage and reliability. Patterns are saved in two versions: one optimized for printing at a user-specified DPI, and one for display. This prevents data loss and allows flexible deployment across different measurement setups.

### Diagnostics for the speckle pattern
The code computes a Fast Fourier Transform (FFT) to analyze average speckle sizes and validate pattern quality. This helps ensure the generated speckles meet experimental requirements.

## Notes for Installation
First clone the repository:
```
git clone https://github.com/Computer-Aided-Validation-Laboratory/specklegen-lg.git
cd specklegen-lg
```

Then create a virtual environment for this project:
```
python -m venv speckle
```

Activate the virtual environment:
```
.\speckle\Scripts\Activate.ps1
```

Then install the dependencies:
```
pip install -e .
```

For this code to work, use a matplotlib version where the `torbg` backend still functions. Recent matplotlib versions may break the saving mechanism.

## Using the code
Run the code using:
```
python main.py input.json
```

If no input file is specified, `input.json` is used by default. The code uses `commentjson` to allow detailed comments in the input deck, making configuration intuitive and documented.

## Testing for development
This code is compatible with pytest. To run a test script from the main directory:
```
python -m pytest tests/loaderTest.py
```
